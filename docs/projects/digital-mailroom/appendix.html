Where the code lives

The linked repository is the integration workspace: one lockfile and one virtual environment wiring the standalone packages together. Package code is authored and released from its own repository, then imported, so a fix belongs upstream rather than in the workspace copy.

Status

Measured capstone results remain unpublished while the project is running, with expected completion in December 2026. This appendix will not carry numbers before the partner-facing report exists.
