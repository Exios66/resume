The global selective-risk sweep reports its error budget as met at a 0.94 threshold, with coverage of about 0.843 at that pick. The multi-window cohort alone does not meet the budget and returns no threshold. Both figures come from the same test pool used for other checks, so treat them as diagnostics, not as independently validated deployment thresholds.

Scope

One checkpoint, one test pool. These tables describe a single release, not a production service level. The test split informed run comparisons, the selective-risk sweep and the decode sweep, so the coverage figures are optimistic. Contract and correspondence stay off the fast path by checkpoint policy.
